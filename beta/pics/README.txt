ORO - launchpad artwork for the scenario descriptions
=====================================================

Drop the screenshots in THIS folder, named exactly as listed below.

The build stages them to <Orbiter>\Images\ORO\ under the same names, and the
description pages in <Orbiter>\Html\Scenarios\ORO\ reference them by that name.
One name from here to the installed tree - nothing is renamed on the way.

RULES
  - lowercase, underscores, no spaces (the name goes into an <img src> URL).
  - 1920 x 1080 is the target (Orbiter's own launchpad picture, Images\CurrentState.jpg,
    is exactly that). Anything 1600 wide or more is fine - it gets normalised here.
    Do not send anything narrower than ~1280: the page scales the image to the pane
    width, so a small source is upscaled and goes soft.
  - JPEG, saved at your grabber's HIGHEST quality setting. A shot that is already
    1920 wide ships exactly as you sent it - no second encode, no generation loss.
    Anything larger or smaller is resized here (one re-encode). The extension does
    not matter; the number and name are what count.
    THE BANNER IS THE EXCEPTION: PNG if your tool can, so the lettering stays crisp.
  - the ORO control panel should NOT be open in the shot. None of these are about it.
  - partial deliveries are fine. A page only gets an <img> when its file exists, so a
    missing shot means that description ships text-only, never a broken-image icon.
